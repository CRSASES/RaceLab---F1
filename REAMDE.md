# RaceLab F1

A personal motorsport data project focused on analyzing and visualizing real Formula 1 telemetry.

The goal of RaceLab F1 is to evolve into a professional motorsport analysis platform, combining telemetry, data engineering, software development and simulation.

## Current Features

* Load real Formula 1 session data using FastF1.
* Access driver telemetry such as speed, throttle, brake, RPM and gear.
* Extract and analyze individual laps.
* Plot telemetry data for visualization.

## Technologies

* Python
* FastF1
* Pandas
* NumPy
* Matplotlib
* Plotly
* SQL (planned)
* FastAPI (planned)

## Purpose

This project is being developed as a hands-on learning and portfolio project, with a focus on applying software engineering and data analysis to motorsport.

The long-term objective is to combine real-world motorsport data with simulation telemetry and build tools capable of identifying performance differences, analyzing driving behavior and supporting race strategy decisions.
